runtime transition map

A compact control panel for moving dotfiles runtime ownership from scattered package managers to mise and uv without losing the CLIs that actually matter.

dotfiles / 2026-06-16

Source of Truth

Runtime manager mise

dot_config/mise/config.toml owns Node, Bun, Python, Ruby, Rust, uv, and gem:colorls.

Python tools uv tool

pipx should stay empty. Python CLIs move through uv tool install.

Shell activation zsh

dot_config/zsh/paths.zsh activates mise and keeps Rust shims available via $CARGO_HOME/bin.

Homebrew role reduced

Keep Homebrew for macOS/system packages. Stop using it as the owner for language runtimes migrated to mise.

When a CLI Disappears

Do not restore old runtime managers just to get a command back. Decide who should own the CLI, then reinstall it intentionally.

Node CLIs

# Make sure npm is the mise-owned npm first.
command -v npm
npm config get prefix

# Then reinstall only the commands you still use.
npm install -g <package>

The Node reinstall cleaned out old global npm shims. That is good hygiene unless one of those CLIs is still active work.

Python CLIs

uv tool install <package>
uv tool list

Ruby CLIs

# Track durable gems in dot_config/mise/config.toml.
"gem:<gem-name>" = "latest"

mise install gem:<gem-name>
