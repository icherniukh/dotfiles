# Inventory

Packages in this repo are laid out as GNU Stow “packages”: each top-level folder mirrors paths under `$HOME`.

Planned packages (initial set):

- `zsh/` → `~/.zshrc`, `~/.zprofile`, `~/.zshenv`, `~/.profile`, and `~/.config/zsh/*`
- `git/` → `~/.gitconfig`, `~/.git-themes`
- `fzf/` → `~/.config/fzf/fzf.zsh`
- `scripts/` → `~/.scripts/*`
- `completions/` → `~/.local/share/zsh/site-functions/*`

Optional app config packages (can be stowed separately):

- `wez/` → `~/.config/wezmux.zsh`, `~/.config/wezaliases.zsh`
- `ghostty/` → `~/.config/ghostty/*`
- `helix/` → `~/.config/helix/*`
- `lazygit/` → `~/.config/lazygit/config.yml`
- `lsd/` → `~/.config/lsd/config.yml`
- `ripgrep/` → `~/.config/ripgrep/config`
- `starship/` → `~/.config/starship.toml`
- `procs/` → `~/.config/procs.toml`
- `yazi/` → `~/.config/yazi/*` (excluding large preview images)
